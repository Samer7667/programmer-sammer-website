PROGRAMMER SAMMER — Website Package
===================================

محتويات النسخة المحدثة:
- index.html: الصفحة الرئيسية الجديدة لهوية Programmer Sammer.
- styles.css: نظام التصميم المتجاوب (RTL، جوال، تابلت، سطح المكتب).
- script.js: قائمة الجوال، تأثيرات الظهور، ونموذج تواصل يجهز رسالة واتساب.
- logo.jpg: الشعار الموجود في ملفات المستخدم.
- programmer-sammer-brand.jpg: الصورة البصرية الحالية للعلامة.
- demos/: ثلاثة نماذج توضيحية للمقهى والمخبز والمطعم.
- CNAME: programmersammer.com.

التوجه الجديد للموقع:
1. Programmer Sammer هي الهوية المهنية الرئيسية.
2. النشاط يجمع بين المنتجات التقنية، الأنظمة المخصصة، وتطوير المواقع.
3. بلّغني معروض كأول منتج قيد دراسة الاحتياج والتطوير، وليس كخدمة تشغيلية متاحة حاليًا.
4. نماذج المقهى والمخبز والمطعم موضحة صراحة بأنها نماذج تجريبية وليست أعمال عملاء.

النشر:
- ارفع محتويات المجلد إلى مستودع الموقع أو الاستضافة الحالية.
- احتفظ بملف CNAME كما هو عند النشر على GitHub Pages.
- لا تغيّر نطاق programmersammer.com أو إعدادات DNS إذا كانت تعمل بالفعل.
- تأكد من أن logo.jpg وprogrammer-sammer-brand.jpg موجودان في جذر الموقع.

التواصل:
- نموذج التواصل لا يخزن بيانات على خادم؛ بل ينشئ مسودة رسالة واتساب.
- رقم واتساب حُفظ كما كان في نسخة الموقع المرفوعة. راجعه قبل النشر إذا تغير.

ملاحظات مهمة قبل النشر:
- راجع رقم واتساب.
- راجع أن وصف بلّغني وحالة التطوير ما زالا يعكسان الوضع الفعلي.
- لا تضف ادعاءً بأن Programmer Sammer مؤسسة أو شركة مسجلة قبل تأسيس الكيان.
- راجع معلومات SEO وروابط الدومين عند تغيير النطاق مستقبلًا.

الموقع ثابت HTML/CSS/JavaScript ولا يحتاج إلى خادم تطبيق أو قاعدة بيانات لتشغيل الصفحة الرئيسية.
